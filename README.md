# Light, Heat, and Spectra

Standalone GitHub Pages build of the `em-radiation` applet from [physics_demos](https://github.com/MartinAlvarezSergio/physics_demos).

Atomic spectra opens by default: H, He, Na, and Ca II with aligned color strips and
intensity curves, selectable wavelengths, line zoom, and compact energy-level and
source–gas–observer diagrams. Blackbody and EM-wave views remain available in Mode.

[Live applet](https://martinalvarezsergio.github.io/em_radiation_playground/) ·
[Atomic data and model](src/applets/em_radiation/ATOMIC_DATA.md)

```bash
npm install
npm run dev
npm run deploy   # build + publish gh-pages
```

# Light, Heat, and Spectra

Standalone GitHub Pages build of the `em-radiation` applet from [physics_demos](https://github.com/MartinAlvarezSergio/physics_demos).

Blackbody spectra (bulb / human / star), atomic emission / absorption lines, and a traveling E–B wave / photon picture with coupled wavelength & frequency.

Live: https://martinalvarezsergio.github.io/em_radiation_playground/

```bash
npm install
npm run dev
npm run deploy   # build + publish gh-pages
```
